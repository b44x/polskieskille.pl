dla agentów AI

Sprawdź firmę, ceny mieszkań, odjazdy, energię lub powietrze w okolicy. Skille dla Claude Code, Cursor, Windsurf, Antigravity i innych agentów — z podanym źródłem danych, czystym JSON i bez zależności pip.

Zobacz w akcji

Jedno pytanie po polsku → agent wybiera skill → skill odpytuje oficjalne źródło → czytelny wynik. Wszystkie dane w filmie pochodzą z rzeczywistych uruchomień skilli.

Około 84 s · 1080p · 10 przykładów · jak powstało demo

Jak to działa

Skill to folder z instrukcją SKILL.md i skryptem CLI. Agent czyta instrukcję, uruchamia skrypt i dostaje ustrukturyzowane dane — zamiast zgadywać.

01

Pytanie

Piszesz normalnie, po polsku.

Sprawdź firmę po NIP 5261040828
02

Agent

Dopasowuje pytanie do opisu skilla.

→ biala-lista
03

Skill

Uruchamia skrypt Python bez zależności.

biala_lista.py nip …
04

Oficjalne źródło

API ministerstwa, banku, instytutu.

wl-api.mf.gov.pl
05

Wynik

JSON dla agenta, odpowiedź dla Ciebie.

Status VAT: Czynny

Jak używać polskich skilli AI?

Co daje skill agentowi?

Instrukcję korzystania z konkretnego źródła i gotowy skrypt do pobrania danych. Możesz sprawdzić firmę po NIP, odczytać kurs NBP lub wyszukać przystanek. Agent dostaje wynik w JSON i wyjaśnia go po polsku.

Czy potrzebuję Claude Code?

Skille mogą działać z Claude Code, Cursor, Windsurf, Antigravity i innymi agentami obsługującymi instrukcje SKILL.md oraz uruchamianie skryptów. Sam skrypt wymaga Python 3.8+; komendy i wymagania znajdziesz na stronie każdego skilla.

Czy dane są zawsze aktualne?

Czas publikacji zależy od źródła. Odjazdy mogą być prognozą lub rozkładem, pomiary powietrza mają własne godziny, a statystyki GUS dotyczą określonych lat. Odpowiedź powinna podawać źródło, datę i braki danych.

Czy korzystanie jest bezpłatne?

Kod projektu jest otwarty na licencji MIT. Skille używają publicznych źródeł opisanych w dokumentacji; dostawcy danych mogą stosować limity zapytań. Część skilli pozwala opcjonalnie podać własny klucz API.
